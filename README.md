# SPACE QUEST — 宇宙探査クイズ

ブラウザだけで遊べる、宇宙探査クイズです。`index.html` に HTML、CSS、JavaScript をまとめており、ビルドやサーバーは不要です。

## クイズの遊び方

1. `index.html` をブラウザで開くか、ローカルサーバーで起動します。
2. 「10問で挑戦」または「3問のクイックチャレンジ」を選びます。
3. 選択肢を選ぶと正誤と解説が表示されます。
4. 最後にスコアと結果が表示されます。

## ローカルでの実行方法

ビルド不要で直接開けます。

```bash
open index.html
```

ローカルサーバー経由で確認する場合は、リポジトリのルートで次を実行します。

```bash
python3 -m http.server 8000
```

ブラウザで `http://localhost:8000/` を開いてください。

## デプロイ

`.github/workflows/deploy-pages.yml` は、`master` ブランチへの変更が push されたときに GitHub Pagesへデプロイします。静的ファイルをそのまま公開するため、ビルド工程はありません。
